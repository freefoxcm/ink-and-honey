# 一笔护汪 · Ink & Honey

在浏览器中打开 [index.html](./index.html) 即可游玩。游戏可以离线运行，无需安装依赖。

按住鼠标或手指，在场地里一笔画出防线。松手后墨线会受重力落下，蜂群倒计时开始。受撞时防线会整体滑动、倾倒或滚动。借地面和高台托稳防线，别让蜂群从缝隙钻进去。所有小狗安全撑过 10 秒即过关，墨水用得越少，通关星星越多。

前六关通过后可以挑战「上下夹击」。这关的小狗分别在石桥上下，要借地形用一笔保护它们。

- **提示**显示当前关卡的一条参考路线。
- **重来**清空当前防线。也可按 `Esc` 重开。
- **键盘**聚焦画布后，用方向键移动画笔，按空格落笔或收笔。按住 `Shift` 可加快移动。
- **声音**默认关闭，可以在右上角开启。最佳星级和解锁进度保存在当前浏览器中。

关卡、时间和墨水预算定义在 [levels.js](./levels.js)。墨线的重量、重力和摩擦参数位于 [ink-physics.js](./ink-physics.js) 顶部。
