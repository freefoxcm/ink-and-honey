# 保卫狗子 · Defend the Pup

在浏览器中打开 [index.html](./index.html) 即可游玩。游戏可以离线运行，无需安装依赖。

按住鼠标或手指，在场地里一笔画出防线。松手后墨线会受重力落下，蜂群倒计时开始。借地面和高台托稳防线，别让蜂群从缝隙钻进去。四组的守护时间依次为 10、12、14 和 16 秒。画线前可以查看出蜂顺序，标有重蜂的波次会带来更强的撞击。倒计时归零时所有小狗安全即过关。

20 关分为地形支撑、风与蜂群、巡逻小狗、活动平台四组。通过每组的第五关挑战后解锁下一组。来到坑边时，留意防线有没有实地支撑，也要挡住蜜蜂能飞过的缝隙。脚印标出小狗的巡逻范围，虚线标出平台的行程。

- **提示**先标出关键落脚点，再次点击可查看完整参考路线。
- **重来**清空当前防线。也可按 `Esc` 重开。
- **键盘**聚焦画布后，用方向键移动画笔，按空格落笔或收笔。按住 `Shift` 可加快移动。
- **声音**默认关闭，可以在右上角开启。最佳星级和解锁进度保存在当前浏览器中。

关卡、时间和墨水预算定义在 [levels.js](./levels.js)。墨线的重量、重力和摩擦参数位于 [ink-physics.js](./ink-physics.js) 顶部。
