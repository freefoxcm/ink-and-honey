# 救我熊命

在手机或电脑浏览器中打开 [index.html](./index.html)。点击「开始游戏」进入地图，再选择一关。手机和电脑使用同一套竖屏关卡，游戏可以离线运行。

小熊偷吃了蜂蜜，蜂群追进了花田。按住鼠标或手指，在场地里一笔画出防线。松手后墨线会受重力落下，蜂群倒计时开始。画线前可以查看出蜂顺序，标有重蜂的波次会带来更强的撞击。倒计时归零时所有小熊安全即过关。

地图串起草地、丛林、湖泊、悬崖、雪山和火山，共 30 关。每章前四关介绍和练习场景的玩法，第五关把几项玩法结合起来，过关后解锁下一章。打开地图时会定位到第一关尚未通关的关卡，已解锁的关卡可以随时重玩。

- **草地**用地面和矮台撑住防线，罩住小熊沿脚印经过的范围。
- **丛林**用树枝和木桩接住小熊。脚印尽头的向下箭头标出了下落位置。
- **湖泊**借移动浮木托住墨线。虚线框标出浮木的行程。
- **悬崖**要照顾上下两层岩沿。留意蜂群是从桥上还是桥下过来。
- **雪山**的风会改变蜂群来路。开局看风向，后续关卡也会换向。
- **火山**的熔岩会缓慢上涨。借高处的岩沿托住小熊，给熔岩留出高度。

- **出蜂批次**在关卡上方按顺序列出，显示每波出发的时间和方向。
- **圆箭头图标**清空当前防线。也可按 `Esc` 重开。
- **键盘**聚焦画布后，用方向键移动画笔，按空格落笔或收笔。按住 `Shift` 可加快移动。
- **声音**默认关闭，可以在首页右上角开启。最佳星级和解锁进度保存在当前浏览器中，旧版正式冒险的进度可以继续使用。

竖屏关卡的地形、参考路线和墨水预算位于 [portrait.js](./portrait.js)。章节顺序、计时和出蜂规则来自 [campaign.js](./campaign.js)。墨线的重量、重力和摩擦参数位于 [ink-physics.js](./ink-physics.js)。
