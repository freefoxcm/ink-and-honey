# 救我熊命

在浏览器中打开 [index.html](./index.html) 即可游玩。游戏可以离线运行，无需安装依赖。

小熊偷吃了蜂蜜，蜂群追进了花田。按住鼠标或手指，在场地里一笔画出防线。松手后墨线会受重力落下，蜂群倒计时开始。画线前可以查看出蜂顺序，标有重蜂的波次会带来更强的撞击。倒计时归零时所有小熊安全即过关。

「正式冒险」有 30 关，按草地、丛林、湖泊、悬崖、雪山、火山的顺序开放。每章前四关介绍和练习场景的玩法，第五关把几项玩法结合起来，过关后解锁下一章。

- **草地**用地面和矮台撑住防线，罩住小熊沿脚印经过的范围。
- **丛林**用树枝和木桩接住小熊。脚印尽头的向下箭头标出了下落位置。
- **湖泊**借移动浮木托住墨线。虚线框标出浮木的行程。
- **悬崖**要照顾上下两层岩沿。留意蜂群是从桥上还是桥下过来。
- **雪山**的风会改变蜂群来路。开局看风向，后续关卡也会换向。
- **火山**的熔岩会缓慢上涨。借高处的岩沿托住小熊，给熔岩留出高度。

「丛林试玩」可以直接进入，五关顺序解锁并单独计星。正式冒险继承对应旧关卡的星级，各章新增的挑战关通过后才会打开下一章。

- **提示**先标出关键落脚点，再次点击可查看完整参考路线。
- **重来**清空当前防线。也可按 `Esc` 重开。
- **键盘**聚焦画布后，用方向键移动画笔，按空格落笔或收笔。按住 `Shift` 可加快移动。
- **声音**默认关闭，可以在右上角开启。最佳星级和解锁进度保存在当前浏览器中。

正式冒险的关卡、计时和墨水预算定义在 [campaign.js](./campaign.js)，原有关卡底稿在 [levels.js](./levels.js)。墨线的重量、重力和摩擦参数位于 [ink-physics.js](./ink-physics.js) 顶部。
